# AI visual asset rules

Use this folder only for clearly labelled AI-generated illustrations, abstract backgrounds, onboarding art, and design drafts.

- Never use an AI image as a real MSU parking area, building, map, vehicle, staff member, or official document.
- Keep user-visible copy in HTML so TH/EN switching and accessibility remain correct.
- Add a short source note in the feature or content record when an AI visual is published.
- Verified MSU photography belongs in the Supabase Storage `parking-media` bucket and must be recorded in `parking_images` with source, alt text, verifier, and verification date.
